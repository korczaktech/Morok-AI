# Apollo — G1

Perfil orientado a baixa latência e rapidez de resposta.

**Implementado:** política greedy com caminho de decodificação simples, limite de saída próprio, alvo CMake `Morok::G1::Apollo` e teste isolado.

Apollo utiliza o motor-base da G1 e não importa código privado dos outros perfis. A prioridade de latência ainda precisa ser confirmada por benchmarks comparativos.
