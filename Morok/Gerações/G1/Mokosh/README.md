# Mokosh — G1

Perfil orientado a eficiência e baixo consumo.

**Implementado:** política de geração própria, limites de saída conservadores, penalidade de repetição, alvo CMake `Morok::G1::Mokosh` e teste isolado.

Mokosh utiliza o motor-base da G1. Não importa código privado de Tsukuyomi, Artemis ou Apollo.
