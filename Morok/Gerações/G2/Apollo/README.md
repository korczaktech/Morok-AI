# Apollo — G2

**Perfil:** modelo comum de uso geral.  
**Orçamento:** 5.000 parâmetros.

O Apollo busca equilíbrio entre capacidade, velocidade e consumo de recursos. É destinado a tarefas cotidianas, sem priorizar o máximo de raciocínio ou a menor latência possível.

A arquitetura e a distribuição dos 5.000 parâmetros, o treinamento e as métricas ainda serão especificados. Esse número é o orçamento de projeto, não uma contagem de parâmetros já implementados.
