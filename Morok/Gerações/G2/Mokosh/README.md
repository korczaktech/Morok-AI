# Mokosh — G2

**Perfil:** modelo rápido.  
**Orçamento:** 2.000 parâmetros.

O Mokosh prioriza velocidade de resposta, baixa latência e menor custo computacional. É adequado para interações frequentes e tarefas diretas; não é o perfil de maior capacidade da geração.

A arquitetura e a distribuição dos 2.000 parâmetros, o treinamento e as métricas ainda serão especificados. Esse número é o orçamento de projeto, não uma contagem de parâmetros já implementados.
