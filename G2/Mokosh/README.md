# Mokosh — G2

Perfil orientado a eficiência e baixo consumo.

**Implementado:** política de geração própria, limites de saída conservadores, penalidade de repetição, alvo CMake `Morok::G2::Mokosh` e teste isolado.

Mokosh utiliza apenas o motor e a composição da G2. Não importa código privado de Tsukuyomi, Artemis ou Apollo.
