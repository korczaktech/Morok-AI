# Tsukuyomi — G2

⚫ Perfil escuro que opera com exatamente um agente.

**Implementado:** contrato com `kAgentCount = 1`, política greedy de agente único, alvo CMake `Morok::G2::Tsukuyomi` e teste isolado.

Tsukuyomi utiliza um único modelo G2 como agente. Os dois especialistas internos da arquitetura G2 não são agentes adicionais. Não importa código privado dos outros perfis.
